# Hébergement et consentement

Ce projet est servi exclusivement par le Nginx de l'utilisateur :
- Dossier publié : `C:/nginx/html/chalons/`
- Adresse : `https://digiaro.duckdns.org/chalons/`

L'utilisateur a explicitement désactivé OpenAI Sites pour ce projet et dans Codex.
Ne pas utiliser Sites, créer de site, rétablir `.openai/hosting.json`, obtenir des
identifiants Sites, ni envoyer le code ou les ressources vers un dépôt ou un
hébergement Sites. Les anciennes configurations et les anciens déploiements
ne constituent pas une autorisation.

Une demande « déploie » concerne uniquement le Nginx ci-dessus. Toute autre
destination de transfert, copie ou publication du projet exige une demande
explicite de l'utilisateur qui nomme cette destination.

Pour publier sur Nginx, préserver le cache IGN servi directement depuis le
projet, sauvegarder les fichiers remplacés, mettre à jour leurs versions gzip
et vérifier le contenu servi en HTTPS.
